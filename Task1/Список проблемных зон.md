# Требования по обеспечению безопаности 

Для начала следует выделить требования по обеспечению безопасности:
1. Хранение ПДн на территории РФ
2. Согласие субъекта на обработку
3. Ограничение доступа к медицинским записям
4. Разграничение доступа (RBAC)
5. Аудит операций с конфиденциальными данными
6. Шифрование ПДн при хранении и передаче

# Архитектурные проактики
1. Privacy by Design
2. Data Lineage / Data Minimalization
3. Шифрование, маскировка, обфускация
4. Прицнип наименьших привелегий
5. RBAC
6. Аудит и логирование
7. Классификация данных

# Список проблемных зон
1. Хранение данных
   2. Данные не шифруются
   3. Нет ограничения доступа к конфиденциальным данным
   4. Нет резервного копирования
   5. Нет механизма уничтожения ПДн
2. Аудит - нет фиксации операций работы с конфиденциальными данными
3. Права - нет разделения прав доступа к данным пациентов
4. Анонимизация - работа происходит с "живыми" данными

# Список данных для защиты
1. Диагнозы и заболевания - шифрование
2. Персональные данные - шифрование при хранении и передаче, маскирование при логировании
3. Платежные данные - обфускация для передаваемых данных, шифрование при хранении и передаче, маскирование при логировании
4. Данные склада - обфускация, обезличивание для отчетности

# Механизм тегирования
Предлагается использовать 3 вида тегов: классификация по чувствительности информации, по типу данных и владелец данных.

## Классификация по чувствительности информации
1. public - публичная информация
2. internal - внутренняя инфомрация компании
3. confidential - ПДн
4. high-confidential - диагнозы, рецепты
5. financial - финансовые данные

## Тип данных
1. pii - ПДн
2. phi - медицинская информация
3. financial - платежные данные
4. storage - складские данные

## Владелец данных
1. patient - пациент
2. docktor - врач
3. storage - склад
4. laboratory - лаборатория

# Список инструментов, способов и мер
1. Шифрование передачи данных - TLS 1.3
2. RBAC - Keycloak
3. Защита от несанкционированного доступа - парольная политика + ДФА 
4. Аудит и логирование - SIEM
